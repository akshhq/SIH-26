The Master 21-Module Custom AI Architecture

Sentinel does not use a single vague black-box model. It runs a coordinated grid of 21 specialized AI and algorithmic modules across 5 distinct analytical domains to detect every statutory violation, cost inflation, work split, and contractor cartel.

1. Compliance & Statutory Intelligence (Modules 1–4)
Statutory Determinism
Module 1: Data Quality & Schema Integrity AI
Pydantic • Hash Sets • Null Profiling • Core MVP

How It Works: Enforces strict data contracts on every raw CSV record streamed from Supabase. Strips summary footers (e.g. "Grand Total"), validates ISO-8601 timestamps, checks boundary amounts, and detects exact byte-level duplicate rows.

Trigger: Duplicate MD5 row hash OR invalid currency string format

Input Datasets: All 12 raw CSV exports (Lok Sabha & Rajya Sabha).
Primary Output: Data Quality Score (0–100) & Bad-Row Quarantine flags.
Real Data Impact: Cleaned 45,806 valid records from raw MoSPI exports.

Module 2: Entity Resolution & Canonical Linkage AI
Levenshtein • Date Delta • Cosine Embeddings • Core MVP

How It Works: Unifies fragmented records across recommendations, sanctions, completions, and expenditures into a single Canonical Work Profile. Uses a 3-tier matching hierarchy (Exact Work ID ──► Composite Key ──► SBERT Cosine > 0.88).

Match Score = 0.50*(ExactID) + 0.30*(District+Sector) + 0.20*(Date±14d)

Input Datasets: Works Recommended, Works Sanctioned, Works Completed, Expenditure.
Primary Output: Unified Master Work Link Graph across Houses.

Module 3: Proposal Intelligence & Price Benchmarking
SBERT all-MiniLM-L6-v2 • Robust District Median • Core MVP

How It Works: Evaluates project proposals at the recommendation stage. Compares proposed unit costs against historical district medians for similar asset categories (e.g. ₹/meter of concrete road or ₹/borewell).

Price Ratio = (Estimated Cost) / (District Category Historical Median)

Input Datasets: Works Recommended (LS & RS), Historical Sanction Archives.
Primary Output: Pre-Sanction Estimate Risk Score (Flags if Cost > 1.8x median).

Module 4: Statutory Guideline Compliance AI
Deterministic Rules Engine • Regex Lexicon • Core MVP

How It Works: Codifies the entire MPLADS Guidelines (Revised 2023) into automated deterministic rules. Checks mandatory 15% SC / 7.5% ST annual quota allocations, ₹25 Lakh/year outside-constituency caps, ₹50 Lakh lifetime repair caps, and flags banned commercial/religious assets.

Banned Regex: (temple|mosque|church|private club|commercial mall|monument)

Input Datasets: Works Recommended, Works Sanctioned, MP Allocation Limits.
Primary Output: Inadmissible Proposal Flags & Exact Statutory Clause Citations.

2. Financial & Anomaly Intelligence (Modules 5–8)
Financial Forensics
Module 5: Cost Anomaly & Unit-Rate Outlier AI
Isolation Forest • Local Outlier Factor (LOF) • Core MVP

How It Works: Trains unsupervised anomaly detection models (Isolation Forest, n_estimators=150) on sanctioned vs. completed costs grouped by state, district, and work category. Isolates statistical cost spikes that deviate significantly from local clusters.

Anomaly Score = -0.5 * (IsoForest Path Length) + 0.5 * (LOF Density Score)

Input Datasets: Works Sanctioned, Works Completed.
Primary Output: Cost Inflation Probability (0–100%) & Outlier Ranking.

Module 6: Timeline Intelligence & SLA Breach Monitor
Chronological State Machine • GFR Milestone Engine • Core MVP

How It Works: Enforces statutory timelines: Recommendation-to-Sanction SLA (≤45 days) and Sanction-to-Completion mandate (≤1 year). Flags 0-day rubber-stamped approvals and chronic project stalling.

Delay Index = (Actual Days Elapsed) / (Mandated SLA Days)

Input Datasets: Works Recommended, Works Sanctioned, Works Completed.
Primary Output: SLA Breach Alerts & Stalled Project Warning Flags.

Module 7: Financial Intelligence & Installment Structuring AI
IQR Frequency Clustering • Ledger Deduplication • Core MVP

How It Works: Detects payment structuring where single projects are paid in up to 52 micro-installments or clustered right below statutory thresholds. Identifies exact duplicate voucher rows in expenditure datasets.

Structuring Flag: Installments ≥ 10 OR (Amount within [₹19,000, ₹19,999] ≥ 5x)

Input Datasets: Expenditure on Completed & On-going Works (LS & RS).
Primary Output: Split Payment Alerts (52x) & Duplicate Payment Ledger Rows (172 LS / 354 RS).

Module 8: Physical–Financial Divergence AI
Ratio Divergence Arithmetic • Milestone Pacing • Core MVP

How It Works: Calculates the Divergence Gap δ = (% Funds Disbursed) - (% Physical Progress). When δ exceeds 35 percentage points (e.g. 88% money drawn vs 30% construction completed), Sentinel raises a severe fiscal advance warning.

δ = (Disbursed / Sanctioned) * 100 - (Physical Progress %); Flag if δ > 35%

Input Datasets: Works Sanctioned, Works Completed, Expenditure.
Primary Output: Advance Misappropriation Risk Score & Fund Freeze Recommendation.

3. Entity, Graph & Network Intelligence (Modules 9, 10, 15)
Network Forensics
Module 9: Duplicate & Split Work Detection AI
Sentence-BERT all-MiniLM-L6-v2 • Cosine Vector Search • Core MVP

How It Works: Converts work descriptions into 384-dimensional dense vectors. Performs approximate nearest neighbor search to detect ghost projects (identical works sanctioned twice in the same ward) and artificial work splitting.

Duplicate Probability = CosineSim(Emb_A, Emb_B) * (1 - CostDifferenceRatio)

Input Datasets: Works Recommended, Works Sanctioned (LS & RS).
Primary Output: Semantic Duplicate Match Percentage (e.g. 94% match) & Cloned Scope Alerts.

Module 10: Vendor Intelligence & Monopoly Index AI
Jaro-Winkler String Clustering • Herfindahl-Hirschman Index (HHI) • Core MVP

How It Works: Standardizes fuzzy vendor name variations (e.g. "AK Singh" vs "Ajay Kumar Singh"). Calculates the Herfindahl-Hirschman Index (HHI) for each constituency to identify vendor monopolies cornering disproportionate contract shares.

HHI = ∑ (Market Share_i)^2; Flag if HHI > 2,500 (Highly Concentrated Monopoly)

Input Datasets: Expenditure (LS & RS).
Primary Output: Vendor Monopoly Score & Shell Contractor Clustering.

Module 15: Graph Intelligence & Collusion Analytics
NetworkX Bipartite Graphs • Betweenness & Degree Centrality • Core MVP

How It Works: Builds a heterogeneous network graph connecting (MP) ──► (Work) ──► (Implementing Agency) ──► (Vendor). Detects self-dealing (where the Implementing Agency and Vendor share matching names/entities) and circular cartel loops.

Cartel Score = Centrality(Vendor) * Weight(MP-Agency Link) * Frequency

Input Datasets: Works Recommended, Works Sanctioned, Expenditure.
Primary Output: Subgraph Visualization of Collusion Rings & IDA Self-Dealing Alerts.

Input: Site Inspection Photos (JPG / PNG).
Primary Output: Photo Reuse Alert & Asset Class / Stage Mismatch Warning.

Input: Photo EXIF GPS Metadata vs Project Master Lat/Lng.
Primary Output: Geofence Breach Flag (e.g. Photo captured 18.7 km away from site).
