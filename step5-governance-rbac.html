7-Role Institutional Governance & On-Site GPS Field Verification

Sentinel enforces least-privilege security across 7 institutional roles: Role + Jurisdiction + Assignment + Permission. No public self-registration, no silent admin deletions, and verified ground field inspections.

The 7 Institutional Personas & Jurisdictions

⚙️ 1. System Administrator

Sole user provisioning authority, RBAC policy enforcement, cloud dataset sync, and system audit log review. Zero public registration.

🏛️ 2. MoSPI Central Officer

National all-India surveillance, national risk thresholds, inter-state disparity analysis, policy copilot queries, and CAG reports.

📍 3. State Nodal Authority

Statewide district monitoring, desk audit assignments, inter-district resource benchmarking, and implementing agency performance reviews.

🇮🇳 4. Member of Parliament

Constituency proposal tracker, live physical milestone updates, remaining entitlement balances, and formal audit clarifications.

🏗️ 5. Implementing Agency (IA)

Submits milestone claims, uploads contractor invoices (RA Bills), and registers measurement book entries. Cannot alter sanctioned budgets.

🔍 6. Vigilance Investigator

Assigned investigation workspace, examines linear evidence chains, issues disbursal freezes, and dispatches field inspection orders.

📋 7. Field Verification Officer

Receives on-site inspection warrants, visits project locations, and uploads live EXIF GPS geotagged photo proof via mobile app.

On-Site GPS Field Verification Workflow

Live Geofence Verification (>250m Check)

1. Field Officer arrives at registered project site with the mobile PWA.
2. App enforces camera-only capture (gallery uploads disabled).
3. Photo EXIF GPS latitude/longitude is validated via Haversine distance.
4. If distance > 250 meters from master project location, the upload is flagged as a Geofence Breach.
